# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-28 — batch 200)
- Slaap-uren (22–7, wijkt voor vlucht).
- Dutje-hold 20/45/90 min + volume-cap.
- Wear: slaap-uren / dutje cyclen.

## Nieuw (2026-09-28 — batch 199)

- Vlucht-hold 2/4/6/8 u + volume-cap.
- Wear: focus / vlucht cyclen.

## Nieuw (2026-09-28 — batch 198)
