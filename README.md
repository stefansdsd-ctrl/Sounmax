# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 95)
- Scenes: Rijles, Ziekenhuiswacht, Practicum/lab, CBR-theorie, Sportdag, Douche-podcast.
- Beste-nu: ochtend rijles/sport, overdag lab/CBR/wachtkamer, stilte-bias examen/lab.
- Zoek: rijles, cbr, lab, sportdag, douche, wachtkamer.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
