# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-21 — batch 121)
- Scenes: Avondspits fiets, Apotheekwacht, Wasstraat lang, Thuis-klus avond, Parkbank, Nachtwinkel kort, Collegezaal+, Regenterras.
- Scene-zoek: lege query + ranking zet favorieten eerst (usage + recent).
- Zoek-aliassen voor batch 121.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload + RemoteViews-widgets

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
