# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-17 — batch 62)
- Chip-zoekveld op Home.
- Chips live: Bus, AH, WFH, Tuin, Zwembad, Sauna, NS-storing, Baby slaapt, Accu laag, Stiltewerk, Stadion, Scooter, Klussen, Nachtbus, Hybride.
- Wear one-taps + Off-reset voor die profielen.

## Eerder (2026-09-17 — batch 61)
- Chips: NS-storing, Baby slaapt, Accu laag, Stiltewerk, Stadion.
- Wear-aliases + one-tap profielen.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
