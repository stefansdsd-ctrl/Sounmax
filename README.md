# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 88)
- Scenes: Lidl-spits, HEMA-rij, MediaMarkt-gang, Fietskelder, Bushalte-kou, Coolblue-ophalen.
- Beste-nu: ochtend halte/kelder, dag winkels, weekend afhaal.
- Zoek-aliassen: lidl, hema, mediamarkt, fietskelder, bushalte, coolblue.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
