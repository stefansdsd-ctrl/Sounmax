# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 87)
- Scenes: Jumbo-spits, IKEA-zondag, Tandarts-wacht, Terras-wind, Lift-echo, Thuis-kids+.
- Beste-nu: luisterdosis tilt naar oor-pauze als weekdrempel is gehaald.
- Zoek-aliassen: jumbo, ikea, tandarts, terras, lift, kids (+ batch 86 aliassen).

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
