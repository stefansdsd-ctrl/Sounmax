# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 90)
- Scenes: PostNL-punt, Etos-rij, Decathlon-hal, Tankstation, Kapperszaak, Flixbus.
- Beste-nu: ochtend tank/flixbus, dag postnl/etos/decathlon/kapper, avond tank/postnl/flixbus, weekend decathlon/etos/flixbus.
- Zoek-aliassen: postnl, pakket, etos, decathlon, tank, pomp, kapper, kapsalon, flixbus, flix.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
