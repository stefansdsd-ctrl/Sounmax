# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-21 — batch 114)
- Scenes: Glasbak, Treinbistro, Koelcel, Schoolfiets, Koffiecorner, Nachtparkeer, Zwembadgang.
- Groep Nieuw (batch 106–114).
- Beste-nu: ochtend schoolfiets, kantoor koffiecorner, avond/nacht nachtparkeer, weekend glasbak/zwembadgang.
- Zoek-aliassen: glasbak, bistro, koelcel, schoolfiets, koffiecorner, nachtparkeer, zwembadgang.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload + RemoteViews-widgets

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
