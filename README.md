# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-26 — batch 180)
- HearingGuard: opt-in max-volume + daglimiet (zacht of hard cap).
- GenreSceneHint: genre/titel → Sport / Werk / Slaap.

## Batch 179
- Glance-widget: zet of wis 1-tap default.
- Wear-commando’s apply_default / pin_default / auto_profile.
- Auto home-profiel op tijdstip (opt-in).

## Volgende
- Wear HearingGuard-tegel
- Genre-hint in MediaSession
- Auto-ANC + codec-probe veldtest
- Find-beep GATT-payload

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
