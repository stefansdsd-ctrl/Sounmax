# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 92)
- Scenes: Zelfscan, Stationshal, Hornbach, Parkeergarage, Thuisbezorgd, IJssalon.
- Beste-nu: ochtend stationshal/garage, dag zelfscan/hornbach, avond thuisbezorgd/ijssalon.
- Zoek-aliassen: scan, cs, bouwmarkt, garage, justeat, takeaway, ijs, gelato.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
