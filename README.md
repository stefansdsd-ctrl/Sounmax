# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-15 — batch 39)
- Home: **Herstel scene** (laatste scene + DSP + volume-ramp).
- Weekrapport: piekdag + uren; zondagavond-notificatie.
- Wear: ANC + Zoek in één rij.

## Nieuw (2026-09-14 — batch 38)
- Auto-ANC + vergeten-headset alert.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Notify-leren testen op TAH6519

## Volgende software
- Glance-only widgets
- GATT find-headset piep
- Lockscreen reconnect

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
