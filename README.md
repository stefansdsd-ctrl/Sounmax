# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-29 — batch 214)
- Warmte-hold: volume-cap + DSP-spaarstand bij accu ≥40°C.
- Hold-prioriteit: ziekenhuis > warmte > lage accu > bedtime.
- BT-herstel: scene + volume terug na reconnect (≤2 uur).
- Wear CMD_CYCLE_THERMAL + CMD_TOGGLE_BT_RESTORE.
