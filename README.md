# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-17 — batch 71)
- Pomodoro 25/5 met oorpauze.
- Slimmere uur-suggestie (weer + dagdeel).
- Zoek op gebruiksfrequentie.
- Duidelijkere find-headset toon.
- Scenes: Oorpauze, Lange rit, Stem-isolatie, Avondrit, Late game, Zachte call.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
