# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 97)
- Scenes: Hardlopen, Teams/vergadering, Dierentuin, E-step/scooter, Nachtmarkt, Wasruimte.
- Beste-nu: ochtend hardlopen/e-step, kantoor Teams, avond markt/was, weekend dierentuin.
- Zoek: prefix op aliassen + hardlopen, teams, zoo, e-step, nachtmarkt, droger.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
