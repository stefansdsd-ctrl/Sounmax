# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-25 — batch 168)
- Suggest-balk max 5 chips; rest via zoek.
- Favorieten + commute + dosis eerst.
- Commute one-tap: laatste pendel-scene + volume-cap.

## Volgende

- Batterij/codec-chip
- Dosis-widget
