# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-22 — batch 133)
- HomePins: 4 vaste scenes op de suggest-balk (Pin-chip wisselt).
- WhyBestNow: chip met korte reden (uur, favoriet, gebruik, accu, dosis).

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload + RemoteViews-widgets

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
