# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-20 — batch 109)
- Scenes: Bibliotheekzaal, Zwembad, Kapsalon, Marktkraam, Eetcafé, Ziekenhuiswacht, Thuiskantoor.
- Groep Nieuw (batch 106–109).
- Beste-nu: doordeweeks ochtend thuiskantoor, lunch eetcafé, weekendmarkt.
- Zoek-aliassen: bieb, kapper, markt, cafe, wachtkamer, homeoffice, garage.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload + RemoteViews-widgets

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
