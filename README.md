# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-10-05 — batch 275)
- Warmte-cap: thermal status matig of hoger en muziek actief, boven 68% → 55%, stapsgewijs. Chip Warmte.
- Banner toont de cap. Opnieuw bij hervatten van de app.
- Zoeker: warmte, hitte, thermal, heet.

## Nieuw (2026-10-05 — batch 274)
- Data-cap: op mobiele data (niet roaming) met muziek actief, boven 70% → 58%, stapsgewijs. Chip Data-cap.
- Banner toont de cap. Opnieuw bij hervatten van de app.
- Zoeker: data, mobiel, metered, stream, 4g, bundel.
