# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-20 — batch 108)
- Scenes: Fietstunnel, Dakterras, Nachtwinkel, Treinwerk, Praktijklokaal, Parkeergarage, Kantoorkantine.
- Groep Nieuw (batch 106–108).
- Beste-nu: weekendavond dakterras, laat avond nachtwinkel.
- Zoek rangschikt nu ook op recent gebruik (niet alleen aantal taps).
- Zoek-aliassen: tunnel, dak, avondwinkel, laptoptrein, lokaal, garage, kantine.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload + RemoteViews-widgets

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
