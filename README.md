# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-24 — batch 155)
- Mid-isolatie, Snap 0,5 dB, V-curve, Scoop, Abs en Presence op de EQ-curve (met undo).

## Batch 154
- Clip6, Peak-norm, Dood-zones, Bass/Treble-isolatie en Jitter op de EQ-curve (met undo).

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
