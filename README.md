# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-25 — batch 166)
- Trein, Winkel, TV, Buiten, Tram, Overleg.
- Wear: Keuken / Game / Bel (+ Café / Werk / Regen).

## Batch 165
- Café, Werk, Regen, Keuken, Game, Bel.
- Wear: Café / Werk / Regen.

## Batch 164
- Podcast, Auto, Gym, Film, Wandel, Radio.
- Wear: Pod / Auto / Film.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
