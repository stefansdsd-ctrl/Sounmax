# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-10-03 — batch 250)
- Video-cap: YouTube/Netflix/Disney/Prime/Twitch boven 76% → 62% (chip Video). Werkt ook zonder notification-access via playback.
- Studie-cap: Anki/Duolingo/Kindle/Libby/Audible boven 58% → 40% (chip Studie).
- Podcast-cap gebruikt nu dezelfde playback-fallback als navigatie.

## Nieuw (2026-10-02 — batch 249)
- Kantoor-cap: ma–vr 09–17 boven 74% → 58% (chip Kantoor).
- Podcast-cap: bekende podcast-app boven 72% → 60% (chip Podcast).
- Volume-wijziging past nu ook Auto-, Sessie-, Doze-, Mic-, Tel-, Accu-, Kantoor- en Podcast-cap toe.

## Nieuw (2026-10-02 — batch 248)
- Sessie-cap: muziek boven 62% langer dan 50 min → 52% (chip Sessie).
- Auto-cap: Android Auto / car-ui boven 80% → 62% (chip Auto).
