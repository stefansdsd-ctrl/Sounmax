# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 89)
- Scenes: Action-hal, Kruidvat-rij, AH to go, P+R parkeren, Wasstraat, Gemeente-loket.
- Beste-nu: ochtend P+R/AH to go, dag Action/Kruidvat/loket, avond Action/Kruidvat, weekend Action/wasstraat/P+R.
- Zoek-aliassen: action, kruidvat, ahtogo, pr, p+r, wasstraat, gemeente, loket.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
