# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-10-01 — batch 231)
- Flip-stil: telefoon face-down → muziek 18% tot omdraaien (chip Flip).
- Nachtladen: 22:00–07:00 aan de lader → volume-cap 35% (chip Laden).

## Nieuw (2026-09-30 — batch 230)
- Schud-aware: schud de telefoon, 12 s volume 25% (chip Schud).
- Negeert schudden in de broekzak.

## Volgende
- Auto-ANC veldtest
- Find-beep GATT-payload (hardware)
- Call-transparantie hardware-veldtest
