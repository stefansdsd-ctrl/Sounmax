# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 91)
- Scenes: OV-poortjes, Snackbar, Woonboulevard, McDrive, Intercity Direct, Picnic-bezorg.
- Beste-nu: ochtend ovpoort/icd, dag woonboulevard/picnic, avond snackbar/mcdrive, nacht icd.
- Zoek-aliassen: ovchip, poortjes, friet, mcdrive, icd, picnic, bezorg.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
