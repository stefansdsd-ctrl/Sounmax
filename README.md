# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-10-02 — batch 248)
- Sessie-cap: muziek boven 62% langer dan 50 min → 52% (chip Sessie).
- Auto-cap: Android Auto / car-ui boven 80% → 62% (chip Auto).

## Nieuw (2026-10-02 — batch 247)
- BT-pauze: ACL-disconnect pauzeert media (chip BT). Terug-play hervat binnen 3 min.
- Tel-cap: telefoon ≤15% + muziek boven 55% → 40% (chip Tel).
- Headset-accu-chip wist zich na BT-drop, zodat Accu-cap niet blijft hangen.

## Nieuw (2026-10-02 — batch 246)
- Accu-cap: headset ≤18% + muziek boven 60% → 42% (chip Accu).
- Terug-play: na los-pauze hervat media als de headset binnen 3 min terugkomt (chip Terug).
