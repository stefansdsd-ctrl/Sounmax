# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-29 — batch 215)
- Limiet-banner: zie waarom volume begrensd is.
- Feature-zoek: holds/scenes op trefwoord.
- Statusbalk toont actieve limiet.
- Wear CMD_LIMIT_STATUS.
