# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-21 — batch 122)
- Scenes: Tuincentrumkas, NS-servicebalie, Kantoorpantry, Fietsenkelder nacht, Ziekenhuis nachthal, Studentenvereniging, Pretparkwacht, Markt sluiting.
- Batch 120–122-aliassen zitten nu in de scene-zoek (niet alleen losse maps).
- Scene-zoek: favorieten + usage + recent blijven eerst.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload + RemoteViews-widgets

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
