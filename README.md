# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-27 — batch 192)
- WearBridge: zoek-telefoon, rusturen-cyclus, skip, mute werken nu.
- Wear: now-playing + ▶/⏸ ⏮ ⏭ volume mute Tel.
- Status: track, playing, rusturen-label.

## Volgende
- Auto-ANC + codec-probe veldtest
- Find-beep GATT-payload

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
