# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-18 — batch 80)
- Scenes: Bieb+, Sportschool-piek, Regenwandeling+, Keukenstoom, Nacht-focus, Perron-spits, Café-praat, Slaap-wind.
- Beste-nu houdt weekend en avond-routines mee.
- Wear: Pauze, Tentamen, Bel, Bieb, Gym, Pit.
- Zoek: bieb, sportschool, regen, keuken, nachtwerk, perron, cafe, slaap.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
