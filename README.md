# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 96)
- Scenes: Fysiotherapie, Bioscoop, Sauna/wellness, Schaatsbaan, Werkcollege, Speeltuin.
- Beste-nu: overdag fysio/college, avond film/sauna, weekend ijs/speeltuin.
- Zoek: fysio, bioscoop, sauna, schaatsen, werkcollege, speeltuin.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
