# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-20 — batch 100)
- Scenes: Rechtbank, Notaris, Fietsenmaker, Waterbus/pont, Consultatiebureau, Skatepark.
- Beste-nu: kantoor-uren zitting/notaris/consultatie, ochtend/avond waterbus, weekend skatepark.
- Zoek: rechtbank, notaris, fietsenmaker, pontje, ggd, skate.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519
- Find-beep payload + RemoteViews-widgets

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
