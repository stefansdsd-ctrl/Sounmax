# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-17 — batch 64)
- Chip-zoekveld filtert de balk live.
- Scene-timer: 15 / 30 / 60 / 90 min → auto-Uit.
- Ontbrekende chips nu écht in de balk: Bus, AH, WFH, Tuin, Zwembad, Sauna.
- Extra one-taps: Hardlopen, Huisarts, File, IKEA, Kapper, NS-storing, Baby slaapt, Accu laag.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
