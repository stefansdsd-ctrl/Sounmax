# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-10-01 — batch 234)
- Route-drop: audio naar speaker (plug/BT los) + muziek boven 32% → 24% (chip Route).
- Piek-cap: volume boven 90% → cap 78% (chip Piek).

## Nieuw (2026-10-01 — batch 233)
- Speaker-drop: headset los + muziek boven 40% → 28% (chip Los).
- Wekker-cap: volgende wekker binnen 25 min + muziek boven 55% → cap 40% (chip Wek).
