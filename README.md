# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw
- Widget- en notificatieknop **Nu**: past de tijdsuggestie meteen toe
- Auto-scene elk uur (als slot uit is)
- Boot-receiver: DSP-service + schema na herstart
- Widget-scene werd alleen in prefs gezet — nu ook écht toegepast
- Focus-sessie 25 min, één-oor, spatial-tegel, head-tracking

## Volgende
- Wear OS-tegel (DSP + scene + batterij)
- Philips ANC via echte GATT-UUIDs

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
