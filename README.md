# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-10-01 — batch 238)
- Sprong-cap: +3 volumestappen binnen 8 s wordt teruggedraaid naar vorige+1 (chip Sprong).
- Lunch-cap: 12:00–13:30 + muziek boven 72% → 55% (chip Lunch).

## Nieuw (2026-10-01 — batch 237)
- Duck-herstel: muziekvolume vóór beltoon/VoIP-duck wordt onthouden en teruggezet als de modus weer normaal is (chip Herstel).

## Volgende
