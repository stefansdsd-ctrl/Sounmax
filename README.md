# Sounmax

Android companion-app voor Philips TAH6519 / Bluetooth-headsets.
10-bands EQ, luister-scenes, AI-tuner, gehoortest, YT Music en LDAC-hulp.

## Nieuw (2026-09-19 — batch 93)
- Scenes: Apotheek, Kinderopvang, Fitness-locker, Stormfiets, Slagerij, Concertfoyer.
- Beste-nu: ochtend stormfiets; dag apotheek/slager/locker; avond opvang/locker; late foyer.
- Zoek-aliassen: pharmacy, opvang, creche, locker, kleedkamer, storm, slager, foyer.

## Nog open (hardware)
- Philips ANC-GATT bevestigen met dump op TAH6519

## Bouwen
Android Studio + JDK 17. API-sleutel Gemini: `.env.example`.
